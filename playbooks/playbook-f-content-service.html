START / TOOL ROUTE
Before you begin

Start with the tools you have.

The output stays the same. Choose how you’ll produce it.

Free workflow

Start with a free writing tool and one free editor: Docs, Sheets, Slides, Canva or a video editor. Use your own files or assets you have permission to use.

Finish one practice output before buying anything. Free-tier limits can change. Save your work and test a free export first.

Paid workflow

Paid AI, design or research tools are optional. Pay for a specific problem, such as a longer source file or repeated editing task.

Read the current plan, country support and credit cost in Tools & costs. Budget for retries. A subscription is not a fixed number of finished deliverables or sales.

Check the current plan and your actual bottleneck before spending.

Make the first version

Use your chosen service’s click-by-click recipe below. Start with one page, clip, listing or row. Review that small piece before producing the full package. Keep editable originals and name files clearly. For websites, publish a tested static preview. For stores, use a proper storefront instead of pretending an HTML page processes orders.

Example for your offer

One-page business website

Complete static website starter ↓ · Rename a copy to index.html.

  1. Pick one business type you understand. Write three common customer questions and one useful next action.
  2. Open ChatGPT, Claude or Z.ai. Paste the website prompt below with those facts. Ask for one self-contained index.html file. Copy only the HTML, without markdown fences, and save it in a new folder. The included website-starter.txt is also a complete editable practice page. Rename a copy to index.html before opening or uploading it.
  3. On Windows use Notepad → Save as → All files → index.html → UTF-8. On Mac use TextEdit → Format → Make Plain Text → save index.html without .txt. Open the file in a browser.
  4. Ask the AI to fix one problem at a time. Paste the relevant code and say what you clicked, expected and saw. Replace sample contact links before sharing.
  5. Open Cloudflare dashboard → Workers & Pages → Create application → Pages / Get started → Drag and drop. Choose a project name, upload the folder and select Deploy site. Labels may move. Use the Direct Upload source below if they differ.
  6. Open the pages.dev URL on your phone. Tap every contact link and check text at a narrow width. Send this preview to a suitable buyer, with permission.
  7. For paid delivery, agree the client-owned account, domain cost, maintenance and changes in writing. Send files and a short update guide. A static page has no working payment system or database by default.

Check your finished workEvery link works, phone text fits, facts are approved, images have rights, and a new visitor can find the contact button. No fake working form.

Creation prompt for this service
Build one self-contained index.html with inline CSS and minimal JavaScript for this fictional demo: [business type], [reader], [offer], [approved facts], [contact URL]. First ask for missing essential facts. Include headline, services, three FAQs, and one clear contact link. Responsive layout, semantic HTML, readable contrast and visible keyboard focus. No framework, backend, checkout, fake reviews or unsupported claims. Do not make a form appear to submit. Give the complete file, saving instructions and a link-by-link phone test. Mark fictional demo visibly.

When you get stuck
I do not know what to make

Open Choose my offer. Pick one small service or product, then use the matching example on each step. Make the smallest version you can check.

AI gives a vague answer

Paste the actual facts and required output. Say which sentence or step is unclear. Ask it to show one filled example and exact next action.

I finished it but nobody bought

Review who saw it, what they asked and where they stopped. Ask a relevant person to try the preview. Change one thing, then test again. Do not treat views as sales.
