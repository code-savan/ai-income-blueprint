START / TOOL ROUTE
Before you begin

Start with the tools you have.

The output stays the same. Choose how you’ll produce it.

Free workflow

Start with a free writing tool and one free editor: Docs, Sheets, Slides, Canva or a video editor. Use your own files or assets you have permission to use.

Finish one practice output before buying anything. Free-tier limits can change. Save your work and test a free export first.

Paid workflow

Paid AI, design or research tools are optional. Pay for a specific problem, such as a longer source file or repeated editing task.

Read the current plan, country support and credit cost in Tools & costs. Budget for retries. A subscription is not a fixed number of finished deliverables or sales.

Check the current plan and your actual bottleneck before spending.

Create it and follow your own instructions

Use the exact build recipe for your product below. Make one section or tab at a time. Replace vague instructions with a click, field or example. Use fictional example inputs and label them. Finish the blank buyer copy separately. Then give it to a tester and watch where they get stuck.

Example for your offer

Freelancer project-start kit

  1. Open the included Freelancer Project Starter to see a complete example. Pick one buyer, such as a new freelance designer.
  2. Ask three freelancers what goes wrong when a project starts. Note the words they use and the free tools they already have.
  3. Open Google Docs → Blank document. Make Start here, Questions to ask, Agreed work, My tasks and Delivery pages. Write original wording.
  4. Fill one fictional project from start to finish. Add a blank copy of each useful page. Test with someone unfamiliar with it.
  5. Export PDF and an editable copy link with safe permissions. Check both in a private browser window. Offer a preview before a paid launch.

Check your finished workA tester can write agreed work, deadlines and a delivery message without asking what a heading means.

Set up delivery without custom coding

  1. Open a supported storefront’s current signup and payout information. Confirm your country, identity requirements, fees and available withdrawal method first.
  2. For Gumroad: open your dashboard → Products → New product → choose the suitable digital-product type → name and price → add your finished content files. Use the current official help if labels differ.
  3. Write the description, add a clear preview and state required software, support and actual refund terms. Check whether the buyer needs a PDF, editable copy link or both.
  4. Use the platform’s test-purchase flow to check the receipt and content access. Open every delivered file and link as a buyer. A test order is not earnings proof.
  5. Publish only after the real files and delivery work. For a physical store, use Shopify or another supported commerce platform. Product records, checkout, shipping, tax and orders need a working store, not a static AI page.
