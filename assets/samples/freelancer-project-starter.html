Freelancer Project Starter.

Organize one small client project from client instructions to approval. This is a fictional prototype you can inspect, not a promise of clients.

Start here / a ten-minute first task

  1. Pick one actual project. Copy the client-question fields into a document or use the worksheet below.
  2. Write the reader and the one action the deliverable should support.
  3. Fill confirmed facts; turn missing facts into questions for the client.
  4. Use the filled copy project below as a reference for agreed work and delivery.
  5. Agree the client instructions before making the work. Complete the final checks before requesting approval.

Editable fields are temporary. Print or save a PDF before closing. For editable delivery, package an actual document/template file and test it with an unfamiliar reader.
