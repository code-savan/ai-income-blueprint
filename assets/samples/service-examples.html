Complete static website starter ↓ · Rename a copy to index.html.

  1. Pick one business type you understand. Write three common customer questions and one useful next action.
  2. Open ChatGPT, Claude or Z.ai. Paste the website prompt below with those facts. Ask for one self-contained index.html file.   3. On Windows use Notepad → Save as → All files → index.html → UTF-8. On Mac use TextEdit → Format → Make Plain Text → save index.html without .txt. Open the file in a browser.
  4. Ask the AI to fix one problem at a time. Paste the relevant code and say what you clicked, expected and saw. Replace sample contact links before sharing.

  6. Open the pages.dev URL on your phone. Tap every contact link and check text at a narrow width. Send this preview to a suitable buyer, with permission.
  7. For paid delivery, agree the client-owned account, domain cost, maintenance and changes in writing. Send files and a short update guide. A static page has no working payment system or database by default.

Check your finished workEvery link works, phone text fits, facts are approved, images have rights, and a new visitor can find the contact button. No fake working form.

Short-video editing

Why this is here: to show what three vertical clips of 20–40 seconds from supplied footage, with cuts and checked captions. looks like.

PRACTICE SOURCE: record yourself reading this 60-second explanation.
Core spoken answer: Before you ask for an event photography quote, send the date, venue and what you want covered. Then confirm hours, final files and when they arrive. A clear enquiry helps both sides agree the work.
30-second edit plan:
0–3: final checklist on screen. Caption: Three details for a clearer quote.
3–8: speaker says date and venue. Cut opening pause.
8–16: show the requested moments and hours as readable text.
16–24: show file type and delivery date questions.
24–30: show final checklist. Caption: Save this before you enquire.
Delivery target: one MP4 practice edit, then three clips for an agreed client package. This text is a shot plan, not finished video footage.
Check: listen and watch muted, correct captions, use only authorized footage/music.

Make your own version

  1. Record your own 60-second explanation for practice. Ask a real client to supply footage they have permission to use.
  2. Open VN or CapCut → New project → add footage. Set vertical 9:16 / 1080 × 1920.
  3. Cut the opening pause. Keep one useful answer, place the clear result early and remove repeats.
  4. Add captions using available free features or manually. Correct names, numbers and punctuation. Keep text clear of interface buttons.
  5. Export 1080p MP4, play with sound and muted, and send three named clips with one agreed revision round.

Check your finished workCaptions match speech, cuts make sense, audio is clear and the final file plays on a phone.
